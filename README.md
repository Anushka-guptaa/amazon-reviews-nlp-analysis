# Amazon Review Sentiment Analysis

This project performs sentiment analysis on Amazon product reviews using Python and VADER Sentiment Analyzer.

## Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Review length analysis
- Word cloud visualization
- Sentiment analysis using VADER
- Sentiment distribution by star ratings

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- WordCloud
- VADER Sentiment

## Dataset
Amazon Reviews Dataset containing:
- Review Score
- Review Text
- Review Summary

## Project Workflow
1. Load dataset
2. Clean review text
3. Create review length feature
4. Perform EDA
5. Generate word clouds
6. Apply VADER sentiment analysis
7. Visualize sentiment trends

## Key Insights
- Most reviews are positive (4–5 stars)
- Higher star ratings generally have higher sentiment scores
- Positive reviews frequently contain words like "good", "love", and "great"
